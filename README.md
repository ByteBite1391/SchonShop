## 📦 نصب و راه‌اندازی

### پیش‌نیازها

- Python 3.10 یا بالاتر
- PostgreSQL (یا SQLite برای توسعه)

### مراحل نصب

#### ۱. کلون کردن پروژه

```bash
git clone https://github.com/yourusername/shop.git
cd shop
```

#### ۲. ساخت محیط مجازی

```bash
python -m venv venv
```

#### ۳. فعال‌سازی محیط مجازی

**ویندوز:**
```bash
venv\Scripts\activate
```

**لینوکس/مک:**
```bash
source venv/bin/activate
```

#### ۴. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

#### ۵. تنظیم متغیرهای محیطی

فایل `.env.example` را به `.env` تغییر نام دهید و مقادیر را تنظیم کنید:

```bash
cp .env.example .env  # لینوکس/مک
copy .env.example .env  # ویندوز
```

سپس فایل `.env` را ویرایش کنید و اطلاعات دیتابیس خود را وارد کنید.

#### ۶. اجرای migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

#### ۷. ساخت superuser

```bash
python manage.py createsuperuser
```

#### ۸. لود کردن داده‌های نمونه

```bash
python seed_data.py
```

#### ۹. اجرای پروژه

```bash
python manage.py runserver
```

حالا به آدرس http://127.0.0.1:8000/ بروید.

## 🔄 سناریوی کامل خرید

1. کاربر وارد صفحه اصلی می‌شود
2. به صفحه محصولات می‌رود
3. محصولات را مشاهده می‌کند
4. از فیلتر و جستجو استفاده می‌کند
5. به صفحه جزئیات محصول می‌رود
6. محصول را به سبد خرید اضافه می‌کند
7. سبد خرید را مشاهده می‌کند
8. تعداد را تغییر می‌دهد یا آیتم را حذف می‌کند
9. برای ثبت سفارش لاگین می‌کند
10. آدرس را وارد می‌کند
11. سفارش را ثبت می‌کند
12. پیام موفقیت می‌بیند
13. سفارش در پروفایل ثبت شده است
14. موجودی محصول کم شده است

## 🎯 نکات فنی

- سبد خرید با Session پیاده‌سازی شده (بدون نیاز به دیتابیس)
- قیمت محصول در زمان سفارش ذخیره می‌شود
- بعد از ثبت سفارش، موجودی محصول کاهش می‌یابد
- کاربر مهمان می‌تواند به سبد اضافه کند
- بعد از لاگین، سبد خرید حفظ می‌شود
- بعد از ثبت سفارش، سبد خالی می‌شود
- محصول غیرفعال در لیست نمایش داده نمی‌شود
- محصول ناموجود قابل افزودن نیست
- هر کاربر فقط سفارش‌های خودش را می‌بیند
- از CSRF Protection استفاده شده
- پسوردها hash شده ذخیره می‌شوند
- از select_related و prefetch_related برای جلوگیری از N+1 Query استفاده شده
- بعد از هر POST، Redirect انجام می‌شود
